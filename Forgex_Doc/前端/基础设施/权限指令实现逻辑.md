# 权限指令实现逻辑

> 分类：前端 / 基础设施
> 版本：**V1.0.0**

## 源码位置

- 指令实现：Forgex_MOM/Forgex_Fronted/src/directives/permission.ts
- 权限状态：Forgex_MOM/Forgex_Fronted/src/stores/permission.ts
- 注册入口：src/directives/index.ts（以实际导出为准）

## 实现流程

v-permission 在 mounted 和 updated 阶段读取绑定值，调用 usePermissionStore().hasPermission。指令把元素原始 display 保存到 __vPermissionOriginalDisplay；没有权限时设置 display:none，有权限或绑定值为空时恢复原始值。指令只隐藏元素，不销毁组件实例，也不阻止脚本直接调用接口。

    组件渲染 -> mounted/updated -> 读取权限 store
            -> hasPermission(permKey)
            -> 无权限隐藏，有权限恢复原 display

## 使用契约

    <a-button v-permission="'sys:user:add'">新增</a-button>

绑定值必须是单个权限字符串。多个权限的 any/all 组合应在脚本中调用 permission store 的对应方法后使用 v-if；不要把数组直接传给当前指令。

## 二次开发与边界

权限列表异步加载后，updated 会重新判断，但路由和接口安全仍由后端 RequirePerm 等机制负责。新增权限码需要同步后端菜单、前端按钮和多语言文案。当前指令没有权限变更事件订阅，实时刷新依赖组件重新渲染或显式刷新权限 store。
