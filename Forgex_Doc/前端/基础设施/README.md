# 前端 / 基础设施

> 版本：`V0.8.5`

本目录沉淀 Web 管理端的基础设施能力，覆盖状态管理、路由菜单、按钮权限、主题样式和表单验证。新增页面或重构公共能力时，应先确认本目录约定，再进入具体组件或业务页面文档。

## 推荐阅读路径

1. 做菜单、页面入口或按钮权限时，先读路由与菜单、权限指令两组文档。
2. 做全局状态、登录态、权限缓存、SSE 连接时，先读状态管理文档。
3. 做页面样式、暗色模式或布局配置时，先读主题与样式体系文档。
4. 做新增/编辑弹窗、抽屉或配置表单时，先读表单验证文档，再联动公共弹窗文档。
