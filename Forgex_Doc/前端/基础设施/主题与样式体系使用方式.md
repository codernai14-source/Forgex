# 主题与样式体系使用方式

> 版本：`V0.8.5`

Forgex 前端主题体系位于 `src/theme`，样式文件位于 `src/styles`。新增页面样式应优先使用主题 CSS 变量和 Ant Design Vue token，避免硬编码颜色、字号、阴影和圆角。

## 一、主题模式

当前支持三类主题模式：

| 模式 | 说明 |
|---|---|
| `light` | 浅色模式 |
| `dark` | 暗色模式 |
| `system` | 跟随系统主题，实际模式由 `useSystemTheme` 解析 |

页面通常不需要直接处理主题切换，只需要使用 CSS 变量和 Ant Design Vue 组件。

主题切换由主布局统一处理，深浅色模式变化时会从页面右上角向左下角执行辐射式过渡动画；业务页面不需要额外编写切换动画。当前实现以旧布局快照作为过渡层，优先使用 `clip-path` 做圆形扩散/收拢动画，浏览器不支持时退化为基础过渡。

暗色模式页面底色统一为 `#14161a`，对应页面底层变量为 `--fx-bg-base` / `--fx-bg-layout`。顶栏、标签栏、侧栏等布局 chrome 也统一为 `#14161a`，组件、卡片、弹窗等容器仍使用 `--fx-bg-container` / `--fx-bg-elevated` 保持层级。

## 二、样式中使用变量

```less
.page-panel {
  background: var(--fx-bg-container);
  color: var(--fx-text-primary);
  border: 1px solid var(--fx-border-color);
  border-radius: var(--fx-radius);
  box-shadow: var(--fx-shadow);
}
```

常用变量：

| 类型 | 变量示例 |
|---|---|
| 背景 | `--fx-bg-base`、`--fx-bg-container`、`--fx-bg-elevated` |
| 文本 | `--fx-text-primary`、`--fx-text-secondary`、`--fx-text-disabled` |
| 边框 | `--fx-border-color`、`--fx-split-color` |
| 主题色 | `--fx-primary`、`--fx-primary-hover`、`--fx-primary-active` |
| 功能色 | `--fx-success`、`--fx-warning`、`--fx-error`、`--fx-info` |

## 三、组件中使用主题

需要读取主题配置时，从统一入口导入：

```ts
import { useAntdTheme, useSystemTheme, resolveThemeMode } from '@/theme'
```

布局级组件负责把主题配置传给 `a-config-provider`；普通业务组件不应重复生成 Ant Design 主题。

## 四、样式约定

- 业务页面样式优先就近写在组件 `<style scoped lang="less">` 或对应模块 less 文件中。
- 公共布局样式放入 `src/styles/main-layout.less` 等公共样式文件。
- 动态表格样式使用 `src/styles/fx-dynamic-table.less`。
- 主布局设置抽屉的表单行统一使用标签固定宽、输入/选择控件固定舒适宽、开关自然宽的布局；较长说明放在 label 旁的 tooltip 图标中；滑块类设置项统一使用 `.fx-setting-row--slider` 与 `.fx-setting-slider`，确保同组滑轨左右对齐；新增设置项时不要复用会把开关拉伸成整行的通用 flex 规则。
- 新增颜色先判断是否已有语义变量，确需扩展时再补 `src/theme/tokens.ts` 和 `cssVariables.ts`。
- 暗色模式下不要使用固定白底或固定深色文字。
