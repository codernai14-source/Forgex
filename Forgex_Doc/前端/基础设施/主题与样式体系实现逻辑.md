# 主题与样式体系实现逻辑

> 版本：`V0.6.5`

主题系统由 `src/theme` 统一维护，核心目标是让 Ant Design Vue 组件和自定义 Less 样式共享同一套 token。

## 一、目录结构

| 文件 | 职责 |
|---|---|
| `types.ts` | 定义 `ThemeTokens`、`ThemeMode`、`LayoutConfig` 等类型 |
| `tokens.ts` | 维护浅色、暗色 token |
| `antdTheme.ts` | 根据布局和模式生成 Ant Design Vue 主题配置 |
| `cssVariables.ts` | 把 token 转换成 `--fx-*` CSS 变量 |
| `presets.ts` | 维护可选主题色盘 |
| `index.ts` | 统一导出主题能力 |
| `useSystemTheme.ts` | 检测系统浅色/暗色偏好并解析最终模式 |

## 二、运行链路

1. 布局配置提供主题模式、主题色、字号、圆角等参数。
2. `useSystemTheme` 监听系统主题。
3. `resolveThemeMode` 将 `light`、`dark`、`system` 解析为实际模式。
4. `useAntdTheme` 生成 `a-config-provider` 的主题配置。
5. `generateCSSVariablesWithCache` 输出 CSS 变量到根节点。
6. 页面 Less 样式通过 `var(--fx-*)` 消费同一套 token。
7. `MainLayout` 在主题切换时会先生成旧布局快照，再以右上角辐射动画覆盖切换，深色布局 chrome 统一使用 `#14161a`。

## 三、Ant Design Vue 集成

Ant Design Vue 组件样式通过主题 token 注入，不建议业务组件单独覆盖组件内部色值。需要统一调整按钮、输入框、表格、弹窗等视觉表现时，应优先修改 token 或公共样式层。

## 四、CSS 变量生成

`cssVariables.ts` 负责把 token 映射成语义变量。变量命名按用途组织，而不是按具体颜色命名，例如使用 `--fx-bg-container`，不要新增 `--fx-white` 这类固定色变量。

暗色模式下，页面底色、顶栏、标签栏、侧栏等布局级区域统一使用 `#14161a`，组件级容器仍保留独立的 `container/elevated` 层级。

## 五、扩展规则

- 增加主题色预设：修改 `presets.ts`。
- 增加全局 token：修改 `types.ts`、`tokens.ts`、`cssVariables.ts`。
- 调整组件库主题：修改 `antdTheme.ts`。
- 调整公共页面布局：修改 `src/styles` 中对应公共 less 文件。
