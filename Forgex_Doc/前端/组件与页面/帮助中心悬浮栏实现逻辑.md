# 帮助中心悬浮栏实现逻辑

> 分类：前端 / 组件与页面
> 版本：**V1.0.0**
> 更新时间：**2026-08-12**

本文说明帮助悬浮栏、覆盖解析、独立上传、站内预览和维护页的前端实现要点。

## 功能定位

帮助中心把「当前页怎么操作」从菜单培训里拆出来：

- 手册 / 视频解决文档和演示
- 联系我们解决找不到文档时的人工入口
- 本页引导复用已有 `FxGuideTour`，做步骤高亮而不是再传一份文档

读写分离：悬浮栏只读；上传、启停、外链维护只在系统管理页。

## 挂载与布局

`MainLayout.vue` 在 `a-layout-content.fx-content` 内挂 `GlobalHelpToolbar`。`.fx-content` 已是 `position: relative`，悬浮栏用绝对定位，不跟随页面内容滚动容器裁切。

本页引导不单独实现 Tour，而是派发 `fx:replay-page-guide`。`MainLayout` 监听该事件后走现有 `hasSystemPageGuide` / `resolveSystemPageGuide` 重放逻辑。无引导配置时第四入口不占位。

路径规范化从 MainLayout 抽到 `src/utils/workspacePath.ts`：

- `normalizeWorkspacePath`：去 query、hash、尾部 `/`
- `buildModuleMenuPath`：按模块编码和菜单相对 path 拼工作区全路径

帮助解析和侧栏高亮共用同一套规则。

## 运行时请求

`src/api/system/helpResource.ts` 统一走 `http` / `httpSuccess` / `silentHttp`：

| 场景 | 方法 | 说明 |
|---|---|---|
| 当前页文档 | `http.post /sys/help-resource/list-for-page` | 打开手册/视频时按需拉取，失败有提示 |
| 联系方式 | 预取用 `silentHttp`，点开用 `http` | 工具栏挂载时预取，打开弹窗再刷新 |
| 管理分页 | `http.post /sys/help-resource/page` | 动态表格 |
| 写操作 | `httpSuccess.post` | 含批量删除 `/sys/help-resource/batch-delete` |
| 上传 | `http.post` + `FormData` | 帮助独立接口，不复用 `/sys/file/upload` |

`list-for-page` 与联系读取不配按钮权限，但仍需登录，不能进网关匿名白名单。

## 预览实现

`FilePreview.vue` 用 `defineAsyncComponent` 懒加载 vue-office，并动态 import 对应 CSS。`marked` / `dompurify` 只在 `.md` 预览时加载。同源文件先 `fetch` + `credentials` 转 Blob，再交给 iframe / vue-office / video。PDF 失败后再切 `@vue-office/pdf`。切换文档用 `:key` 重挂 Office 组件。

外链 `sourceType=EXTERNAL_URL` 且不是 mp4 直链时，不内嵌预览，直接给新窗口 / 下载。`.doc` 不走 Office 组件，避免伪预览。

`PublicFileController` 对 `docx` / `doc` / `pdf` / `xlsx` 等返回正确 MIME，不再一律兜成 `application/octet-stream`。

## 维护页实现

`views/system/helpResource/index.vue`：

1. 手册 / 视频 Tab 共用一张动态表，请求时强制带当前 `docType`
2. 菜单树来自 `getMenuTree`，用当前权限模块编码拼全路径后写入 `menu_path`
3. `scopeType` 切到 `GLOBAL` 时清空 `menuId` / `menuPath`
4. 路由 query `docType`、`menuPath`、`tab` 用于从运行时弹窗带入维护上下文
5. 联系 Tab 独立表单，二维码预览同样走 `normalizeMediaUrl`
6. 工具栏支持批量上传（多文件依次 upload + create）和批量删除
7. 操作列预览复用 `FilePreview`，表格用 `useBatchTableSelection` 勾选行

路由注册在 `src/router/index.ts`：`SystemHelpResource -> views/system/helpResource/index.vue`。菜单 `component_key` 必须一致。

## 关键约束

- `@RequirePerm` 在后端是 AND。前端不要把新增和编辑合成一个「保存」接口。
- 不要把全局 `FileUploadConfig.maxSizeMb` 提到 200。视频上限走 `system.help.upload.videoMaxSizeMb`，由帮助上传接口覆盖。
- 标题仍是单字段 `title`，本期不做文档正文多语言、全文检索、反馈工单、观看进度和 Android。
