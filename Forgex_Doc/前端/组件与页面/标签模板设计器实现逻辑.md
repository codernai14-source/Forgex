# 标签模板设计器实现逻辑

> 分类：前端 / 组件与页面

本文说明标签模板设计器、预览页和打印页的前端实现逻辑。

## 页面结构

模板管理页使用动态表格承载列表，主操作按钮包括：

- 新增
- 编辑
- 删除
- 预览
- 设计

设计器使用抽屉全屏展开，避免离开列表页。

## 设计器数据结构

模板详情组件对象主要包含：

- `componentType`
- `positionX`
- `positionY`
- `componentWidth`
- `componentHeight`
- `componentContent`
- `dataSource`
- `fieldCode`
- `styleJson`
- `sortNo`

其中：

- `dataSource = FIXED` 表示固定值
- `dataSource = FIELD` 表示业务字段绑定

## 画布渲染

画布按照纸张宽高换算为像素进行展示，组件在页面上以绝对定位方式渲染。

交互实现包括：

- `mousedown` 开始拖动
- `mousemove` 更新坐标
- 右下角手柄缩放宽高
- 点击选中组件并在右侧属性面板编辑

## 字段联动

右侧属性面板通过标签字段接口加载字段下拉项。

当组件切换到业务字段模式时：

1. 显示字段下拉框
2. 选择字段编码
3. 保存到组件详情的 `fieldCode`

## 样式编辑

文本组件支持基础样式编辑：

- 字号
- 字重
- 对齐方式

样式以 JSON 字符串存储在组件详情中，前端编辑后直接回写。

## 预览与打印

模板预览页通过模板详情接口读取渲染后的结构，展示模板整体效果。

打印页通过后端渲染接口拿到最终 VO，前端直接按返回结构渲染，不再解析实体对象。

## 兼容说明

如果后续新增组件类型，需要同时补齐：

1. 设计器组件库
2. 画布渲染样式
3. 属性面板配置
4. 打印页渲染逻辑
