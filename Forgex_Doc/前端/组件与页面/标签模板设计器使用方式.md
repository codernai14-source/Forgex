# 标签模板设计器使用方式

> 分类：前端 / 组件与页面

本文说明标签类型、标签字段、标签模板列表页、设计器和打印页的使用方式。

## 页面入口

| 页面 | 入口 |
|---|---|
| 标签类型 | `src/views/label/type/index.vue` |
| 标签字段 | `src/views/label/field/index.vue` |
| 标签模板 | `src/views/label/template/index.vue` |
| 标签打印 | `src/views/label/print/index.vue` |

## 标签类型页

标签类型页提供分页查询、新增、编辑、删除和启停。

常用操作：

1. 输入类型编码或类型名称查询
2. 点击新增维护分类
3. 在列表中切换启用状态

## 标签字段页

标签字段页提供分页查询、新增、编辑、删除、启停和导入。

字段导入使用公共导入弹窗，页面只负责传入稳定的导入编码并在导入完成后刷新列表。

## 标签模板页

标签模板页提供模板主表的增删改查、预览和进入详细设计。

主表仅维护：

- 模板编码
- 模板名称
- 模板类型
- 版本
- 是否启用
- 纸张尺寸

点击“设计”会打开全屏抽屉进入设计器。

## 设计器使用

设计器分为三栏：

1. 左侧模板属性和组件库
2. 中间画布
3. 右侧组件属性

组件库包含：

- 文本框
- 条形码
- 二维码
- 图片
- 横线
- 竖线

画布支持：

- 拖拽移动
- 右下角缩放
- 选中高亮
- 删除组件

右侧属性支持：

- 固定值 / 业务字段切换
- 字段下拉选择
- 字体大小
- 字体粗细
- 对齐方式
- 坐标与尺寸修改

## 打印页

打印页接收后端渲染结果，直接按纸张尺寸渲染并调用浏览器打印。

它不再解析业务实体，只负责：

1. 接收渲染后的模板数据
2. 按组件类型绘制内容
3. 触发浏览器打印

## 使用建议

1. 文本组件优先使用业务字段绑定，固定值适合标题和常量。
2. 设计时先保存主模板，再保存组件详情。
3. 打印前先走预览，确认字段映射是否正确。
4. 组件位置和尺寸以毫米为准，不要直接按像素理解。
