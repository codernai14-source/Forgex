# 缺省页（403 / 404 / 离线）（使用方式）

> 分类：前端 / 组件与页面  
> 版本：**V0.6.6**  
> 更新时间：**2026-05-17**

Forgex 工作台内统一使用路由缺省页展示无权限、路由不存在与网络不可用等状态，避免各业务模块重复写占位页面。

## 代码位置

| 说明 | 路径 |
|---|---|
| 页面组件 | `Forgex_MOM/Forgex_Fronted/src/views/fallback/index.vue` |
| 样式 | `Forgex_MOM/Forgex_Fronted/src/styles/views/fallback/index.less` |
| 路由 | `Forgex_MOM/Forgex_Fronted/src/router/index.ts` |
| 文案 | `Forgex_MOM/Forgex_Fronted/src/locales/*/fallback.ts`（如 `zh-CN/fallback.ts`） |

## 路由约定

主布局下子路由形式：

```text
/workspace/fallback/403
/workspace/fallback/404
/workspace/fallback/offline
```

路由片段在 `router/index.ts` 中通过正则约束：`path: 'fallback/:kind(403|404|offline)'`。

## 如何使用

### 1. 编程式跳转

```typescript
import { useRouter } from 'vue-router'

const router = useRouter()

// 无菜单权限或业务拒绝访问
router.push('/workspace/fallback/403')

// 未知路由、菜单未同步
router.push('/workspace/fallback/404')

// 网关不可达、断网等（可由 HTTP 拦截器统一处理）
router.push('/workspace/fallback/offline')
```

### 2. 全局兜底

`router/index.ts` 中可将未知子路径重定向到 `/workspace/fallback/404`，并由守卫跳过对缺省页自身的二次重定向（现有逻辑中对 `/workspace/fallback/` 前缀有特殊判断，避免死循环）。

### 3. 国际化

所有标题、描述、检查清单、按钮文案使用 `fallback.*` 命名空间；新增语种时复制 `fallback.ts` 到对应 locale 并在 `locales/*/index.ts` 中合并。

### 4. 页面操作

- **403 / 404**：主按钮跳转工作台首页 `/workspace/home`，次按钮浏览器后退。
- **offline**：主按钮为整页 `location.reload()`，便于网络恢复后重试。
