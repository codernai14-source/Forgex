# 缺省页（403 / 404 / 离线）（实现逻辑）

> 分类：前端 / 组件与页面  
> 版本：**V0.6.6**  
> 更新时间：**2026-05-17**

## 组件职责

`views/fallback/index.vue` 根据路由参数 `kind` 在 `403`、`404`、`offline` 三种呈现间切换：

- 使用 `computed` 从 `route.params.kind` 解析 `pageKind`，非法值回落为 `404`。
- 每种 `pageKind` 对应一组 **视觉配置**（状态码展示、检查项 key 列表）与 **动画格子** 高亮集合，保证三种状态视觉区分度一致。

## 主题与样式

样式位于 `styles/views/fallback/index.less`，使用工作台已有的 CSS 变量（与「主题与样式体系」一致），避免硬编码浅色/深色两套色值。

## 路由协作

- 缺省页挂在 **工作台布局** 下，以便仍显示顶栏/侧栏上下文（若产品设计要求全屏空白页，可再拆独立 layout）。
- `router/index.ts` 对 `fallback` 路径做守卫处理，防止未登录或重复重定向逻辑把用户锁在循环中。

## 扩展方式

1. 新增一种缺省类型：在路由正则、`FallbackPageKind`、`pageConfigs` 与各语言 `fallback.ts` 中同步增加键。
2. 与 HTTP 层联动：在 `http.ts` 响应拦截器里对网络错误、502/503 统一 `push('/workspace/fallback/offline')`（按项目现有策略执行）。
