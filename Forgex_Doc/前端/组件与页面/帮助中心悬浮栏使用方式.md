# 帮助中心悬浮栏使用方式

> 分类：前端 / 组件与页面
> 版本：**V1.0.0**
> 更新时间：**2026-08-12**

本文说明工作区右下角帮助悬浮栏、只读预览弹窗、帮助资源维护页和公共文件预览的接入方式。

## 代码位置

```text
Forgex_MOM/Forgex_Fronted/src/components/help/GlobalHelpToolbar.vue
Forgex_MOM/Forgex_Fronted/src/components/help/HelpResourceModal.vue
Forgex_MOM/Forgex_Fronted/src/components/help/HelpContactModal.vue
Forgex_MOM/Forgex_Fronted/src/components/common/FilePreview.vue
Forgex_MOM/Forgex_Fronted/src/views/system/helpResource/index.vue
Forgex_MOM/Forgex_Fronted/src/api/system/helpResource.ts
Forgex_MOM/Forgex_Fronted/src/utils/workspacePath.ts
```

悬浮栏挂在 `MainLayout.vue` 的 `a-layout-content.fx-content` 内，与回到顶部按钮同级。只出现在登录后工作区，不挂 `App.vue`。

## 运行时入口

登录后任意工作区页面右下角会出现圆形问号。展开后提供：

| 入口 | 行为 |
|---|---|
| 操作手册 | 按当前页路径解析启用中的手册，只读预览 |
| 操作视频 | 按当前页路径解析启用中的视频，只读播放 |
| 联系我们 | 展示 `system.help.contact` 配置，含二维码 |
| 本页引导 | 仅当 `hasSystemPageGuide(当前路径)` 为真时显示，点击重放 `FxGuideTour` |

点击手册 / 视频会走带提示的 `http` 拉列表，成功后再开弹窗并收起竖条；失败会提示，不会出现「点了没反应」。展开后的子按钮与主按钮同为 48px 圆钮。

打开弹窗后竖条会收起，展开状态写入 `localStorage` 键 `fx-help-toolbar-expanded`。定位为 `right:24px; bottom:96px; z-index:30`，避开 `.fx-back-top`。

弹窗内不能上传文件。有 `sys:help:view` / `add` / `edit` 之一时，手册和视频弹窗底部提供「维护本页文档」；有 `sys:help:contact:edit` 时联系弹窗提供「维护联系方式」。跳转路径：

```text
/workspace/sys/maintenance/helpResource?docType=MANUAL|VIDEO&menuPath=<当前工作区路径>
/workspace/sys/maintenance/helpResource?tab=contact
```

## 覆盖解析

前端把 `normalizeWorkspacePath(route.fullPath)` 传给 `POST /sys/help-resource/list-for-page`。后端按当前类型解析：

1. 启用中的 `MENU` 精确匹配
2. 同类型最长 `menu_path` 前缀（子页吃父菜单文档）
3. 再回退 `GLOBAL`

返回 `resolvedScope=MENU|GLOBAL`。列表标签显示「本页专属 / 通用手册」。无文档时引导先看「联系我们」。

`menu_path` 必须是与侧栏相同的工作区全路径（例如 `/workspace/sys/user`），不要写 `sys_menu.path` 相对值。管理页选菜单时由 `buildModuleMenuPath` 写入解析后的全路径。

## 维护页

路由组件键：`SystemHelpResource`，菜单路径 `helpResource`，页面标题为「帮助中心」。页面三个 Tab：

- 操作手册 / 操作视频：`FxDynamicTable`，`table-code=SystemHelpResourceTable`
- 联系我们：读写 `system.help.contact`

手册 / 视频表格支持搜索、新增、批量上传、批量删除、预览、启停。批量上传对每个文件先调 `/sys/help-resource/upload`，再用文件名创建元数据。预览复用 `FilePreview`。表格列含格式（`fileExt`）和大小（`fileSize`），已有环境需执行 `20260911_help_resource_table_columns.sql`。

新增或编辑时：

- 范围切到 `GLOBAL` 会清空菜单绑定
- 范围 `MENU` 必须选菜单，并写入解析全路径
- 来源 `FILE` 先调 `POST /sys/help-resource/upload` 再提交元数据
- 来源 `EXTERNAL_URL` 填 http(s) 地址，不走扩展名校验
- 联系二维码走 `POST /sys/help-contact/upload-qr`，不要走 `/sys/file/upload`

权限：

| 操作 | 权限码 |
|---|---|
| 打开维护页 / 分页 | `sys:help:view` |
| 新增、上传手册或视频 | `sys:help:add` |
| 修改元数据、启停 | `sys:help:edit` |
| 删除、批量删除 | `sys:help:delete` |
| 保存联系方式、上传二维码 | `sys:help:contact:edit` |
| 运行时 list-for-page / 读联系方式 | 登录即可 |

权限种子只预授 admin，不默认给全部业务角色。

## 公共预览

`FilePreview.vue` 可给帮助弹窗、维护页预览和后续通知附件复用。同源文件先带凭证拉成 `blob:` 再交给预览组件，避免 `docx` / `pdf` 被后端兜成 `application/octet-stream` 后 Office 组件渲染失败。切文档时用 `:key` 强制重挂。按扩展名分流：

| 格式 | 方案 |
|---|---|
| PDF | Blob iframe，失败再懒加载 `@vue-office/pdf` |
| DOCX | Blob + 懒加载 `@vue-office/docx` |
| XLS / XLSX | Blob + 懒加载 `@vue-office/excel` |
| TXT | fetch + `<pre>` |
| MD | `marked` + `DOMPurify` 后 `v-html` |
| MP4 | Blob / `<video>` |
| DOC | 提示下载或转 docx |
| 外链 | 默认同窗口失败后新窗口；可识别的 mp4 直链再尝试播放 |

失败态固定提供「新窗口打开 / 下载」。展示本地文件 URL 必须先走 `normalizeMediaUrl()`。预览区需保持最小高度，避免弹窗空白。
