## 适用场景

- 做多语言字段录入、标题与正文配置：优先看多语言输入两篇文档。
- 做首页、工作台、拖拽布局类页面：优先看个人首页与可拖拽布局两篇文档。
- 处理历史页面中已存在的硬编码中文展示或提示：先确认 `src/utils/legacyI18n.ts` 与 `src/locales/legacyText.ts` 是否已有兼容翻译；新增页面不要继续依赖该兼容层，应直接使用 `t(...)` 或后端统一返回消息。

## 五语言页面修复说明

- 正式支持语言固定为 `zh-CN`、`en-US`、`zh-TW`、`ja-JP`、`ko-KR`。
- 公共动态表格会优先解析后端 `title_i18n_json` / `table_name_i18n_json` 等 JSON 字段，也支持前端兜底配置直接传 i18n key。
- 页面按钮、操作菜单、查询项、弹窗标题和确认文案应直接使用 `t(...)` / `$t(...)`；`legacyI18n` 仅作为历史 DOM 文案兜底。
- `FxDynamicTable` 不再支持前端 fallback 表格配置，表格列、查询字段与列名必须由后端表格配置接口返回；页面端仅负责渲染，不再维护本地备份配置。
- 前端新增 `npm run i18n:audit`，用于检查五语言 locale 文件结构、key 差异、非 locale 文件中文候选文案，以及数据库 JSON 字段五语言覆盖情况。
- 数据库侧五语言 JSON 缺失可参考 `Forgex_Doc/数据库/脚本与修复/20260508_i18n_five_language_repair.sql`，该脚本只补现有字段，不新增表结构。

## 主布局菜单说明

- `vertical` 模式只显示单列左侧菜单，不启用第二列菜单。
- `vertical-mix` 模式左侧第一列显示模块，第二列递归显示当前模块下目录、菜单和按钮节点。
- `top` 水平模式不显示左侧菜单，点击顶部模块后在内容区上方显示该模块菜单入口卡片。
- 布局设置中的字号只展示“小 / 默认 / 大”等语义标签，实际配置仍保存为 `px` 字符串。
- 左侧二级菜单折叠入口为底部小按钮样式，不再使用 Ant Design Sider 默认整条底部触发栏。
- 顶栏和标签栏之间只保留标签栏顶部一条细分割线，避免重复边框。
