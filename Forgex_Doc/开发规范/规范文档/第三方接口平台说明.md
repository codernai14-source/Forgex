# 第三方接口平台说明

> 分类：开发规范 / 后端契约
> 版本：**V1.0.0**

本文只规定外部系统接入 Forgex 的 `Forgex_Integration` 平台。Forgex 内部服务互调另见[内部服务接口说明](./内部服务接口说明.md)。

## 接入边界

第三方接口配置、授权、参数映射、调用日志和异步结果查询由 Integration 模块负责；业务模块不直接暴露第三方认证和转换逻辑。

## 推荐流程

1. 创建第三方系统并配置授权信息。
2. 创建 API 定义和请求参数。
3. 配置源字段到目标字段的映射与转换规则。
4. 使用统一出站门面发起调用，保存调用日志。
5. 异步调用通过任务 ID 查询结果，回调接口必须做幂等处理。

## 代码示例

前端通过 Integration API 模块调用平台接口：

```ts
import http from '@/api/http'

const result = await http.post('/integration/api-config/page', {
  pageNum: 1,
  pageSize: 20,
})
```

具体路径、签名字段和映射类型必须以 `Forgex_Integration` Controller 及 `src/api/system/integration.ts` 当前源码为准；源码未提供的第三方能力应标记为未实现，不在文档中虚构。
