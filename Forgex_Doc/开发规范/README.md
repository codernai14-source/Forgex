# 开发规范文档导航


## 三、当前纳入的规范范围

| 类别 | 内容 |
|---|---|
| 架构设计 | 仓库结构、服务边界、上下文透传、前后端协作关系 |
| Git 规范 | 提交消息、分支管理、协作流程 |
| 数据库规范 | 字段统一规范、命名与通用审计字段 |
| ORM 规范 | MyBatis-Plus 使用约束 |
| 注释规范 | Java / TypeScript 注释基线 |
| 组件接入规范 | 公共表格、HTTP 请求、国际化与消息提示 |
| 测试规范 | 单元测试、集成测试、接口验证、AI 自动化测试范围与报告模板 |

## 四、正式维护入口

- 通用研发规范维护在 `Forgex_Doc/开发规范/规范文档/`。
- 模块级能力说明维护在 `Forgex_Doc/后端`、`Forgex_Doc/前端`、`Forgex_Doc/数据库`、`Forgex_Doc/部署` 等正式分类。
- 数据库初始化脚本维护在 `Forgex_Doc/部署/数据库初始化脚本/`。
- 已有环境专项修复和诊断 SQL 维护在 `Forgex_Doc/数据库/脚本与修复/`。

## 六、维护原则

1. **架构变更先更新这里，再修改模块文档。**
2. **通用规则写在这里，模块差异写到各自专题文档。**
3. **新的公共规范，应优先放在 `Forgex_Doc/开发规范`。**
