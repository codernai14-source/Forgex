# 项目架构设计文档

> 版本：**V0.8.5**
> 更新时间：**2026-08-12**

## 一、文档目标

本文档用于说明 Forgex 当前的项目结构、核心技术边界、前后端协作方式，以及后续文档应该如何围绕这些边界进行组织。

## 二、项目定位

Forgex 是一套面向企业级场景的全栈开发脚手架，核心目标是把企业项目里高频、重复、跨模块复用的能力沉淀为统一底座，减少业务项目从零搭建成本。

当前仓库覆盖三端：

- Web 管理端：`Vue 3 + TypeScript + Vite`
- Backend 微服务：`Spring Boot 3 + Spring Cloud + Spring Cloud Alibaba`
- Android 移动端：`Kotlin + Compose + Hilt + Retrofit + DataStore`

## 三、仓库结构

forgex

## 四、后端架构分层

### 4.1 可运行业务服务

| 模块 | 主要职责 |
|---|---|
| `Forgex_Auth` | 登录、验证码、注册、租户选择、第三方登录、权限内部接口 |
| `Forgex_Sys` | 系统管理、字典、消息中心、国际化、仪表盘、动态表格、编码规则 |
| `Forgex_Workflow` | 流程配置、流程发起、待办/已办、审批执行、撤回/委托、回调 |
| `Forgex_Report` | 报表分类、模板、数据源、设计与预览 |
| `Forgex_Gateway` | 网关统一入口、上下文透传、跨服务访问入口 |
| `Forgex_Job` | 分布式任务调度接入（含工作流超时扫描等 Bean 任务） |
| `Forgex_Basic` | 基础主数据与业务扩展 |
| `Forgex_Integration` | 第三方接口平台、出入站编排与调用日志 |

### 4.2 公共能力与契约模块（原单体 Common 已拆分）

Java 包名仍以 `com.forgex.common.*` 为主，**Maven 按能力 / 提供方拆分**：

| 模块 | 主要职责 |
|---|---|
| `Forgex_Common_Contract` | `R`、状态码、公共异常、提示契约 |
| `Forgex_Common_Core` | 租户/用户/语言上下文、轻量枚举与基础 Param |
| `Forgex_Common_Web` | MVC 拦截、Feign Token 透传自动配置 |
| `Forgex_Common_Data` | `BaseEntity`、租户/数据权限拦截 |
| `Forgex_Common_Crypto` | 密码、传输、字段、文件加密 |
| `Forgex_Common_Excel` | Excel 导入导出公共能力 |
| `Forgex_Common_Infra` | 许可证、审计、字典、表格配置、MQ、通知、全局异常/i18n Advice 等 |
| `Forgex_Domain_Contract` | 跨服务共享 DTO / 必要注解 |
| `Forgex_*_Api` | 各服务对内 Feign 契约（Auth/Sys/Basic/Job/Workflow/Integration） |
| `Forgex_Common` | **迁移期兼容聚合**（无实现源码）；新代码禁止新增依赖 |

二开依赖选型与新增 Feign 步骤见：[Common 模块化拆分与二开指南](../../后端/公共能力/Common模块化拆分与二开指南.md)。

### 4.3 设计原则

1. **公共能力模块只提供公共能力，不依赖业务实现模块。**
2. **内部 Feign 归属提供方 `*_Api`，消费者按需依赖；`*_Api` 之间不互依赖。**
3. **Auth 负责认证与权限来源，不承载具体业务实现。**
4. **Sys 负责平台基础能力，Workflow/Report/Basic/Integration 负责领域能力。**
5. **所有服务通过统一上下文读取租户、用户、语言信息。**
6. **业务服务使用精确 Maven 依赖，不为省事回退到 `Forgex_Common` 聚合包。**

### 5.1 文档入口

- 前端能力清单与架构精要：[Forgex_Doc/前端/README.md](../../前端/README.md)（唯一入口）。

前端设计原则：

1. **接口调用不在页面里直接处理重复消息提示。**
2. **公共交互优先抽象到 `components/common`。**
3. **表格类页面优先采用配置驱动接入。**
4. **权限、动态路由、租户态统一通过全局链路收口。**

## 六、核心上下文链路

### 6.1 登录与租户链路

```text
前端登录 -> Auth 返回用户态/租户列表 -> 选择租户 -> Gateway 透传上下文
-> 下游服务写入 TenantContext / UserContext / LangContext -> 业务执行
```

### 6.2 国际化链路

```text
前端请求头 X-Lang / Accept-Language
-> LangWebInterceptor / LangContext
-> R + I18nPrompt / I18nBusinessException
-> RMessageI18nAdvice 翻译
-> 前端 http.ts 消费 message 并提示
```

### 6.3 动态表格链路

```text
页面传入 tableCode + request
-> FxDynamicTable 拉取表格配置
-> CommonTableController / FxTableConfigService 组装配置
-> 页面 request 拉业务数据
-> ColumnSettingButton 保存用户个性化列设置
```
