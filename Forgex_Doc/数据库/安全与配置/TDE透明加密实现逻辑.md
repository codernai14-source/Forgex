# TDE透明加密实现逻辑

> 分类：数据库 / 安全与配置
> 版本：**V1.0.0**

## 源码位置与能力边界

Forgex_MOM/Forgex_Backend 中没有 MySQL TDE 开关、密钥管理器或 TDE 迁移脚本；数据库目录 Forgex_Doc/数据库 也没有可执行 TDE 初始化 SQL。因此 TDE 不是当前产品代码已实现的功能，本页只记录部署评估边界。

应用层加密的实现位于 Forgex_MOM/Forgex_Backend/Forgex_Common_Crypto 及各业务加密服务，和数据库磁盘加密是两条独立链路。

## 评估流程

    确认 MySQL/云数据库版本和 TDE 能力
     -> 设计 KMS/密钥轮换与备份恢复
     -> 在副本环境验证性能、恢复和迁移
     -> 评审应用层字段加密是否仍需保留
     -> 形成部署方案后再执行 DBA 变更

## 二次开发与下一步

若要产品化 TDE，需要新增受支持数据库矩阵、部署脚本、密钥托管接口、备份恢复文档和自动化验收；不能仅在配置文件增加一个 encrypt=true。当前下一步是由 DBA 选定目标数据库并提供可重复的启用/回滚步骤，再将其纳入 Forgex_Build 部署流程。
