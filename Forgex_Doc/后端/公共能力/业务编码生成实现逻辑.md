# 业务编码生成（实现逻辑）

> 分类：后端 / 公共能力  
> 版本：**V0.6.6**  
> 更新时间：**2026-05-17**

## 设计目标

- **统一入口**：各业务模块不直接依赖 `Forgex_Sys` 的编码规则实现，避免模块间循环依赖。
- **远程生成**：实际序号递增、规则解析在 Sys 完成；Common 仅做 Feign 调用与错误收敛。
- **便于调用**：`EncodeUtils` 提供静态方法，适合在纵向业务 Service 中一行生成编码。

## 调用链

```text
业务 Service
  -> EncodeUtils.nextEncode(ruleCode)
       -> EncodeRuleService.generateCode(ruleCode)
            -> EncodeRuleFeignClient.generateCode(ruleCode)  // POST /sys/encodeRule/feign/generate
                 -> Forgex_Sys 编码规则服务
```

## 核心类职责

| 类 | 职责 |
|---|---|
| `EncodeUtils` | Spring `@Component`；通过 `@Autowired` setter 将 `EncodeRuleService` 赋给静态字段；对外暴露 `nextEncode(String ruleCode)`。 |
| `EncodeRuleService` | 校验 `ruleCode`；`ObjectProvider<EncodeRuleFeignClient>` 延迟取客户端，避免未启用 Feign 时启动失败；解析 `R<String>`，非成功抛 `RuntimeException`。 |
| `EncodeRuleFeignClient` | `@FeignClient(name = "forgex-sys", contextId = "encodeRuleFeignClient")`，请求体为 **纯文本** `ruleCode`（`@RequestBody String`）。 |

## 数据与规则

- 规则元数据、流水号存储在 Sys 侧（如 `fx_encode_rule` 及相关表，以库内实际表名为准）。
- `ruleCode` 必须由运维/产品在 Sys 中维护且处于启用状态，否则生成会失败。

## 异常与日志

- `EncodeRuleService` 在 Feign 不可用或返回失败时打 **error** 日志并抛出运行时异常，调用方应按业务需要捕获或向上抛出。
- `EncodeUtils` 在静态依赖未注入时抛 `IllegalStateException`，用于尽早发现测试/启动配置问题。
