# 编码规则实现逻辑

> 分类：后端 / 配置与审计
> 版本：**V1.0.0**

## 源码位置

- 控制器：Forgex_MOM/Forgex_Backend/forgex-admin/forgex-admin-sys/Forgex_Sys/src/main/java/com/forgex/sys/controller/SysEncodeRuleController.java
- 服务：Forgex_Sys/src/main/java/com/forgex/sys/service/impl/SysEncodeRuleServiceImpl.java
- 校验与渲染：同目录 EncodeRuleDetailValidator.java、EncodeRuleRenderer.java
- 跨服务契约：Forgex_Sys_Api/src/main/java/com/forgex/common/feign/client/EncodeRuleFeignClient.java

## 请求链路

Controller 内部前缀是 /encodeRule，网关常见外部前缀是 /basic/encodeRule。接口包括 POST /page、/list、/get、/save、/delete、/batchDelete、/generate、/enable、/disable。保存按 id 是否为空选择 basic:encodeRule:add 或 basic:encodeRule:edit 权限；生成需要 basic:encodeRule:generate。

generate 接收 GenerateCodeParam，只有 ruleCode 字段，调用 ISysEncodeRuleService.generateCode(ruleCode) 返回字符串。Feign 客户端通过 @RequestBody String ruleCode 调用 Sys 的生成服务，业务模块只依赖 Forgex_Sys_Api。

## 规则渲染和整体流程

规则主表和明细由 SaveParam 传入，明细类型由 EncodeRuleDetailValidator 限制为 FIXED、DATE、SEQUENCE、VARIABLE。EncodeRuleRenderer 按明细顺序拼接固定文本、日期格式、序列号和变量值；序列号的递增及持久化由 SysEncodeRuleServiceImpl 完成。启用/禁用通过修改规则状态控制。

```text
维护规则 -> 校验编码和明细 -> 保存主表/明细
       -> 业务传入 ruleCode -> 读取启用规则
       -> 渲染各段并递增序列 -> 返回 R<String>
```
