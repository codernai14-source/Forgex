# 数据字典使用方式

> 分类：后端 / 配置与审计
> 版本：**V1.0.0**

## 源码与接口

管理接口来自 SysDictController，网关通常使用 /sys/dict 前缀：

- POST /sys/dict/tree、/page：管理树和分页，需要 sys:dict:view。
- POST /sys/dict/items：请求体 {dictCode}，返回当前语言的项。
- POST /sys/dict/itemsByPath：请求体 {nodePath}。
- POST /sys/dict/create、/update、/delete：当前租户增改删。
- POST /sys/dict/pull-public：复制公共 tenantId=0 字典。
- POST /sys/dict/refresh-cache：清除当前租户 Redis 键。

## 前端基础调用

```ts
import http from '@/api/http'

const items = await http.post('/sys/dict/items', { dictCode: 'status' })
const byPath = await http.post('/sys/dict/itemsByPath', { nodePath: 'user/status' })
const tree = await http.post('/sys/dict/tree', { publicConfig: false })
```

响应项包含 value、label、tagStyle；项目的 http 封装可能已解包 R.data，直接使用 Axios 时应检查 code === 200。

## 管理和公共字典示例

```ts
await http.post('/sys/dict/create', {
  dictCode: 'order_status',
  dictName: '订单状态',
  dictValue: 'pending',
  parentId: 0,
  moduleId: 1,
  status: 1,
  dictValueI18nJson: '{"zh-CN":"待处理","en-US":"Pending"}',
  tagStyleJson: '{"color":"#1677ff"}',
})
await http.post('/sys/dict/pull-public')
await http.post('/sys/dict/refresh-cache')
```

公共配置树通过 tree/page 的 publicConfig=true 查询；普通租户读取项时会自动合并公共项和租户项，租户同 value 会覆盖公共项。删除父节点前必须先删除子节点。

## 后端响应自动翻译

```java
public class UserVO {
    @DictI18n(nodePathConst = "user/status", targetField = "statusText")
    private Integer status;
    private String statusText;
}
```

targetField 必须是已存在的 String 字段。当前 advice 写入的是包含 label 和 tagStyle 的 JSON 字符串，不是纯文本；前端应按项目约定解析。

## 推荐用法与排错

- 推荐固定使用 nodePathConst 或稳定的 nodePathField，不要把显示名称当作路径。
- items 返回空：检查 dictCode 是否是根节点编码、租户是否已拉取公共字典、项 status 是否为 1。
- 更新后仍是旧值：先调用 refresh-cache；多节点环境还要确认 Redis 发布主题可达。
- 翻译字段为空：确认 TenantContext 已建立、targetField 存在且当前语言 JSON 有值；解析失败会静默保留原值。
- publicConfig=true 查询的是 tenantId=0，只有具备对应管理权限的后台调用方才能维护。
- /common/dict/cache/invalidate、warmup、stats 的真实前缀取决于网关路由，调用前先核对网关配置。
