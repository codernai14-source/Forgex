# 审计日志实现逻辑

> 分类：后端 / 配置与审计
> 版本：**V1.0.0**

## 源码位置

- 查询接口：Forgex_MOM/Forgex_Backend/Forgex_Sys/src/main/java/com/forgex/sys/controller/SysOperationLogController.java
- 本地记录器：Forgex_Sys/src/main/java/com/forgex/sys/audit/SysOperationLogRecorder.java
- 切面与契约：Forgex_Common_Infra/src/main/java/com/forgex/common/audit/OperationLogAspect.java、OperationLog.java、OperationLogRecord.java
- 跨服务回写：RemoteOperationLogRecorder.java、OperationLogFeignClient.java
- 哈希链：Forgex_Sys/src/main/java/com/forgex/sys/audit/AuditChainService.java
- 表实体：Forgex_Sys/.../domain/entity/SysOperationLog.java

## 记录流程

业务方法标记 OperationLog 后，OperationLogAspect 在方法前后包裹执行。它读取 TenantContext、UserContext 和当前 HTTP 请求，序列化参数与响应，过滤请求对象、文件流并遮蔽 password、privateKey、keyHex、secret、accessKey 等字段，响应和异常文本分别限制长度。R<T> 的响应状态取 R.code，二进制下载只记录 [binary response omitted]。无论成功还是异常，finally 都尝试调用 OperationLogRecorder。

Sys 服务存在 SysOperationLogRecorder 时直接写 sys_operation_log；其他服务使用 RemoteOperationLogRecorder 通过 Feign 调用 Sys 的 POST /operationLog/internal/record。记录器还会按租户、模块、模板编码读取 SysOperationTemplate，用当前语言选择 textI18nJson，并替换 {field} 占位符生成 detailText。

## 哈希链

写入前 AuditChainService.fill 按租户读取最新 recordHash，使用 operationTime、userId、requestUrl、requestParams、responseResult 拼接内容，再计算 SM3(prevHash|content) 写入 prevHash 和 recordHash。verify 按 id 顺序重算并检查链指针和哈希；任一不一致返回 false。链校验不是数据库约束，直接修改历史行可能破坏链。

## 查询和导出流程

SysOperationLogController 提供 POST /operationLog/page、/export、/verify-chain、/internal/record。page 按 TenantContext 过滤，支持 module、operationType、account、username、userId、startTime、endTime；时间接受 yyyy-MM-dd HH:mm:ss 或 ISO_LOCAL_DATE_TIME。查询结果再批量补充 account。export 委托 ExcelExportService，verify-chain 需要 sys:operation-log:verify，查询和导出分别需要 view/export 权限。

## 二次开发边界与现状

新增审计字段需同时扩展 OperationLogRecord、实体、数据库列和远程 Feign DTO。不要在业务方法自行写 sys_operation_log，否则会绕过脱敏和链计算。当前 recorder 记录失败会被切面吞掉或远程记录器降级为 warn，主业务不会因审计故障回滚；需要强一致时应设计独立可靠投递。长期归档、SIEM 推送和链头签名不在现有源码中，不能宣称已完成。
