# 编码规则使用方式

> 分类：后端 / 配置与审计
> 版本：**V1.0.0**

## 源码与接入方式

实现入口是 SysEncodeRuleController，内部路径 /encodeRule，网关外部通常为 /basic/encodeRule。权限码为 basic:encodeRule:query、add、edit、delete、generate。业务服务生成编码应依赖 Forgex_Sys_Api 的 EncodeRuleFeignClient。保存 DTO 的明细字段是 detailList，段长度字段是 segmentLength。

## 维护规则示例

```ts
import http from '@/api/http'

const saved = await http.post('/basic/encodeRule/save', {
  ruleCode: 'sales_order',
  ruleName: '销售订单',
  module: 'basic',
  isEnabled: true,
  detailList: [
    { segmentOrder: 1, segmentType: 'FIXED', segmentValue: 'SO' },
    { segmentOrder: 2, segmentType: 'DATE', dateFormat: 'yyyyMMdd' },
    { segmentOrder: 3, segmentType: 'SEQUENCE', segmentLength: 4, sequenceStart: 1, paddingChar: '0' },
  ],
})
await http.post('/basic/encodeRule/enable', { id: saved.data })
```

具体字段以 EncodeRuleSaveParam、EncodeRuleDetailSaveParam 为准；明细类型只能使用 FIXED、DATE、SEQUENCE、VARIABLE，未知类型会被校验器拒绝。

## 生成编码

```ts
const result = await http.post('/basic/encodeRule/generate', { ruleCode: 'sales_order' })
const code = result.data
```

```java
@Resource
private EncodeRuleFeignClient encodeRuleFeignClient;

public String nextCode() {
    R<String> result = encodeRuleFeignClient.generateCode("sales_order");
    if (result.getCode() != 200) {
        throw new IllegalStateException(result.getMessage());
    }
    return result.getData();
}
```

Feign 方法的请求体是原始字符串，不是 {ruleCode} 对象；只有 HTTP Controller 的 /generate 接收 {ruleCode: "..."}。

## 高阶场景、推荐和排错

订单、物料等写入事务中先生成编码，再保存业务实体；业务唯一约束仍需数据库保证。停用规则后生成接口应返回业务错误，调用方不要缓存旧规则。多租户场景使用当前租户上下文，公共规则需由服务层明确支持。

- 404：确认网关使用 /basic/encodeRule，服务间使用 Feign。
- 403：检查 basic:encodeRule 权限；save 会按新增/编辑分别检查。
- 规则不存在或未启用：调用 /get 检查明细和状态。
- 生成重复编码：检查序列段长度、数据库唯一约束和目标环境并发；当前仓库未完成真实压力验证。
- 返回对象取值错误：统一按 R.code == 200 和 R.data 读取。
