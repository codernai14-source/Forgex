# 帮助资源使用方式

> 分类：后端 / 模块专题
> 版本：**V0.8.5**
> 更新时间：**2026-08-12**

本文说明帮助手册 / 视频 / 联系方式的接口、权限、上传上限和已有环境升级方式。前端悬浮栏接入见 [帮助中心悬浮栏使用方式](../../前端/组件与页面/帮助中心悬浮栏使用方式.md)。

## 数据落点

| 数据 | 库 / 键 | 说明 |
|---|---|---|
| 手册与视频 | `forgex_admin.sys_help_resource` | 业务表，继承 `BaseEntity` |
| 联系我们 | `forgex_common.sys_config` 键 `system.help.contact` | JSON：phone / email / wechatQrUrl / address / workTime / remark |
| 视频上传上限 | `forgex_common.sys_config` 键 `system.help.upload` | `{ "videoMaxSizeMb": 200 }` |

`MENU` 必须同时有 `menu_id` 和 `menu_path`；`GLOBAL` 二者必须为空。`menu_path` 存工作区全路径。

## 接口

网关已覆盖 `/api/sys/**`，无需新路由。全部 POST，不要进匿名白名单。

| 接口 | 权限 | 说明 |
|---|---|---|
| `/sys/help-resource/page` | `sys:help:view` | 管理分页 |
| `/sys/help-resource/create` | `sys:help:add` | 元数据新增 |
| `/sys/help-resource/update` | `sys:help:edit` | 元数据更新 |
| `/sys/help-resource/delete` | `sys:help:delete` | 逻辑删除 |
| `/sys/help-resource/batch-delete` | `sys:help:delete` | 批量逻辑删除，入参 `{ ids }` |
| `/sys/help-resource/change-status` | `sys:help:edit` | 启停 |
| `/sys/help-resource/upload` | `sys:help:add` | 先传文件拿 URL |
| `/sys/help-resource/list-for-page` | 登录即可 | `docType` + `menuPath` 覆盖解析 |
| `/sys/help-contact/get` | 登录即可 | 读联系配置 |
| `/sys/help-contact/save` | `sys:help:contact:edit` | 写联系配置 |
| `/sys/help-contact/upload-qr` | `sys:help:contact:edit` | 联系二维码，`moduleCode=sys_help_contact` |

写操作已加 `@OperationLog`。提示码走 `SysPromptEnum.HELP_*`，Controller 不硬编码中文。

## 上传规则

不要复用 `/sys/file/upload`：该接口额外要求 `sys:file:upload`，且默认体积只有 20MB。

帮助上传内部仍调 `FileService`，但：

- 手册 `moduleCode=sys_help_manual`，扩展名 `pdf,doc,docx,xls,xlsx,txt,md`，体积走全局上传上限
- 视频 `moduleCode=sys_help_video`，扩展名 `mp4`，体积走 `videoMaxSizeMb`（默认 200）
- 联系二维码 `jpg,jpeg,png`
- `EXTERNAL_URL` 不走扩展名校验，只允许 http(s)，禁止 `javascript:` 等

Nacos `forgex-common.yml` 的 multipart 需至少 200MB，才能让视频请求进入业务校验。不要把全局 `FileUploadConfig.maxSizeMb` 提到 200。

公开预览 `GET /sys/files/**` 需返回正确 MIME：`docx` / `doc` / `pdf` / `xlsx` / `xls` / `txt` / `md`，不要一律兜成 `application/octet-stream`，否则前端 Office 预览会失败。

## 覆盖解析

`list-for-page` 在 Service 内写死：

1. 规范化 path（去 query、去尾 `/`）
2. 启用中的 `MENU` 精确匹配
3. 同 `doc_type` 下按 `menu_path` 最长前缀
4. 仍无则 `GLOBAL`

返回 `{ resolvedScope, menuPath, items[] }`。
