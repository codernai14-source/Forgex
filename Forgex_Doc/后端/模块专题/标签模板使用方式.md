# 标签模板使用方式

> 分类：后端 / 模块专题

本文说明标签类型、标签字段、标签模板以及打印渲染接口的使用方式。

## 适用场景

- 维护标签分类、字段和模板主数据
- 在前端完成标签模板拖拽设计
- 按模板编码把业务实体解析为可直接渲染的打印结构

## 菜单与权限

标签模块保留 `/basic/label/*` 入口，主要权限如下：

| 功能 | 权限码 |
|---|---|
| 标签类型查询 | `label:type:query` |
| 标签类型新增 / 编辑 | `label:type:add` / `label:type:edit` |
| 标签类型删除 | `label:type:delete` |
| 标签字段查询 | `label:field:query` |
| 标签字段新增 / 编辑 | `label:field:add` / `label:field:edit` |
| 标签字段删除 | `label:field:delete` |
| 标签模板查询 | `label:template:query` |
| 标签模板新增 / 编辑 | `label:template:add` / `label:template:edit` |
| 标签模板删除 | `label:template:delete` |
| 标签设计保存 | `label:template:edit` |
| 标签打印渲染 | `label:print:execute` |

## 标签类型

标签类型页面用于维护标签分类，后端接口如下：

- `POST /basic/label/type/page`
- `POST /basic/label/type/detail`
- `POST /basic/label/type/add`
- `POST /basic/label/type/update`
- `POST /basic/label/type/delete`
- `POST /basic/label/type/enable`
- `POST /basic/label/type/options`

主要字段：

- 类型编码 `typeCode`
- 类型名称 `typeName`
- 是否启用 `isEnabled`

## 标签字段

标签字段页面用于维护模板可绑定的业务字段，后端接口如下：

- `POST /basic/label/field/page`
- `POST /basic/label/field/detail`
- `POST /basic/label/field/add`
- `POST /basic/label/field/update`
- `POST /basic/label/field/delete`
- `POST /basic/label/field/enable`
- `POST /basic/label/field/options`

标签字段支持导入，前端通过公共导入组件发起，后端接入公共 Excel 导入能力。

主要字段：

- 字段编码 `fieldCode`
- 字段名称 `fieldName`
- 字段类型 `fieldType`
- 模块 `moduleId`
- 是否启用 `isEnabled`

## 标签模板

标签模板主表只负责基础信息，模板明细由设计器保存到详情表。

接口如下：

- `POST /basic/label/template/page`
- `POST /basic/label/template/detail`
- `POST /basic/label/template/add`
- `POST /basic/label/template/update`
- `POST /basic/label/template/delete`
- `POST /basic/label/template/batchDelete`
- `POST /basic/label/template/setDefault`
- `POST /basic/label/template/preview`
- `POST /basic/label/template/design/detail`
- `POST /basic/label/template/design/save`

模板主表常用字段：

- 类型 `typeId`
- 模板编码 `templateCode`
- 模板名称 `templateName`
- 版本 `version`
- 是否启用 `isEnabled`
- 纸张宽高 `paperWidth`、`paperHeight`

## 详细设计

设计器支持的组件类型：

- `TEXT`
- `QRCODE`
- `BARCODE`
- `IMAGE`
- `HORIZONTAL_LINE`
- `VERTICAL_LINE`

设计器保存的组件详情包含：

- 组件类型
- 位置 `positionX`、`positionY`
- 尺寸 `componentWidth`、`componentHeight`
- 内容 `componentContent`
- 数据来源 `dataSource`
- 绑定字段 `fieldCode`
- 样式 `styleJson`
- 排序 `sortNo`

文本组件支持两种模式：

1. 固定值
2. 业务字段绑定

其中业务字段来自标签字段表，前端在右侧属性面板切换数据来源后选择字段即可。

## 打印渲染

公共打印渲染接口：

- `POST /basic/label/print/render`

入参核心字段：

- `templateCode`
- `data`
- `printCount`

处理逻辑：

1. 根据 `templateCode` 查找模板主表和组件详情
2. 将 `data` 统一转换为字段 `Map`
3. 按组件绑定字段名从实体中取值
4. 业务字段命中的组件返回替换后的最终内容
5. 固定值组件保持原值
6. 返回前端可直接渲染的结构化结果

返回结果包含：

- 模板编码
- 模板名称
- 纸张配置
- 打印张数
- 组件列表

前端打印页只负责渲染返回结果并调用浏览器打印，不再解析业务实体。

## 使用建议

1. 字段编码尽量保持业务语义一致，避免同一含义出现多个命名。
2. 设计器组件位置和尺寸统一按毫米保存。
3. 打印前先通过预览接口校验模板详情和字段映射。
4. 业务实体字段名需要与模板绑定字段名一致，例如模板绑定 `matName`，实体也应提供 `matName`。
