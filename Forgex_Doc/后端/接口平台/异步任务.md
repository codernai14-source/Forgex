# 异步任务

> 分类：后端 / 接口平台 / 任务  
> 版本：**V1.0.0**

## 源码位置

`ApiTaskServiceImpl.java`、`ApiTaskConsumer.java`、`ApiTaskResultServiceImpl.java`、实体 `ApiTask`/`ApiTaskResult`。任务表为 `fx_api_task`，结果表为 `fx_api_task_result`，队列由 Redis 实现。

## 运行方式

将接口或出站目标的 `invokeMode` 设为 `ASYNC`，调用得到 taskId：

```java
IntegrationExecuteResult result = integrationFacade.invoke("erp_user_sync_async", payload);
String taskId = result.getAsyncResults().get(0).getTaskId();
```

公共入站则调用 `/api/integration/public/task/{taskId}` 查询。任务消费者恢复快照和上下文后执行入站处理器或出站请求，将状态和结果写入结果表，并补写调用日志。

## 错误和限制

任务已受理不等于第三方成功；必须读取结果状态和 `errorMessage`。任务不存在、结果尚未落库、处理器异常和目标超时要分别处理。当前源码未提供取消任务、人工重放或死信管理 API；二开应先补状态机、幂等键和重试上限，避免重复同步。
