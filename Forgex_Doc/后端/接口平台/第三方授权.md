# 第三方授权

> 分类：后端 / 接口平台 / 授权  
> 版本：**V1.0.0**

## 源码位置

`ThirdAuthorizationController.java`、`ThirdAuthorizationServiceImpl.java`、`ThirdAuthorizationDTO.java`、`ApiGatewayServiceImpl.authorizeInbound`；前端授权弹窗为 `src/views/integrationPlatform/thirdSystem/components/ThirdSystemAuthDialog.vue`。

## 模式和接口

授权类型只有 `TOKEN`、`WHITELIST`、`TOKEN_WHITELIST`。管理权限为 `integration:third-system:auth`。

| 方法 | 路径 |
|---|---|
| POST | `/api/integration/third-authorization/page`、`/list`、`/create`、`/update`、`/batch-delete` |
| GET | `/api/integration/third-authorization/detail/{id}`、`/by-system/{thirdSystemId}`、`/validate-token?tokenValue=...` |
| POST | `/api/integration/third-authorization/delete/{id}`、`/generate-token/{thirdSystemId}` |

## 配置示例

```ts
import { addThirdAuthorization, generateThirdAuthorizationToken } from '@/api/system/integration'
await addThirdAuthorization({
  thirdSystemId: 1001, authType: 'TOKEN_WHITELIST',
  whitelistIps: '192.168.3.7,10.0.0.8', tokenExpireType: 'DAY',
  tokenExpireValue: 30, status: 1,
})
const token = await generateThirdAuthorizationToken(1001, { tokenExpireType: 'FOREVER' })
```

同一第三方系统只有一条有效授权；调用 create 时已有记录会进入 update。Token 可按小时、天、月、年、自定义时间或永久；白名单 IP 以逗号、分号或换行分隔，精确匹配来源 IP。`WHITELIST` 不保存 Token，`TOKEN_WHITELIST` 命中白名单免 Token，非白名单必须带有效 Token。

## 入站调用如何传凭证

公共请求可在 `token`、`authToken` 或 `authorization.token` 中传值；系统 ID 可传 `thirdSystemId`/`third_system_id`，也可在接口的 `authConfig` 中绑定：

```json
{"thirdSystemId":1001}
```

网关先检查绑定系统白名单；未绑定系统则检查任一白名单；最后校验 Token 是否启用且未过期。授权失败写调用日志并返回 `API_AUTH_FAILED`。

## 错误处理和边界

白名单模式缺少 `whitelistIps`、Token 模式过期、授权停用、绑定系统不存在都会失败。不要把 Token 放 URL 查询参数或日志；当前源码仍会将原始请求记录到调用日志，生产环境二开应对 `token/authToken/authorization` 做脱敏。

## 二开

新增签名（如 HMAC、OAuth2）需扩展授权类型、凭证存储、`authorizeInbound` 和前端表单，并增加重放保护；仅增加枚举值不会自动生效。
