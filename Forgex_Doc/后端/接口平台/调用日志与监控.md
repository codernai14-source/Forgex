# 调用日志与监控

> 分类：后端 / 接口平台 / 监控  
> 版本：**V1.0.0**

## 源码与接口

日志链路位于 `ApiGatewayServiceImpl.writeLog`、`ApiLogBufferServiceImpl`、`ApiCallLogServiceImpl`、`ApiCallLogTableServiceImpl`。管理接口需要 `integration:api-call-log:view`：

`POST /api/integration/call-log/page`、`/list`；`GET /detail/{id}?callTime=...`、`/count`、`/success-rate`。

```ts
import { getApiCallLogList, getApiCallLogDetail } from '@/api/system/integration'
const page = await getApiCallLogList({ pageNum: 1, pageSize: 20, callStatus: 'FAIL', callDirection: 'OUTBOUND' })
const detail = await getApiCallLogDetail(page.data.records[0].id, page.data.records[0].callTime!)
```

日志保存 `rawRequestData`、`requestData`、`assembledRequestData`、`responseData`、状态、结果类型、错误、耗时、traceId、taskId、目标系统和调用时间。出站 `assembledRequestData` 可还原 body/query/headers/pathVariables/targetUrl。

## 动态月表

表名为 `fx_api_call_log_yyyyMM`。服务启动时创建当月和下月表，定时检查当月，写入前再次兜底；查询先跳过不存在月份表，因此历史缺表不会直接导致页面报错。动态 SQL 查询仍显式附加当前租户条件，不能把月表当作绕过租户隔离的入口。

## 首页概览

`GET /api/integration/dashboard/overview`，权限 `integration:home:view`，前端 `getIntegrationDashboardOverview()`。统计第三方系统、接口、今日调用、成功率、方向、状态、近 14 天趋势、高频接口和失败调用。

## 排错与安全

按 `traceId → taskId → callTime` 串联；先看原始请求，再看组装请求和响应。当前日志会保存原始凭证字段，二开生产环境必须增加 token/header 脱敏和访问审计。日志写入失败只记录服务日志，不应阻断业务响应。
