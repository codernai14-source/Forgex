# 公共入站接口

> 分类：后端 / 接口平台 / 入站  
> 版本：**V1.0.0**

源码：`PublicIntegrationController.java`、`PublicInvokeRequest.java`、`ApiGatewayServiceImpl.invokeInbound`。入口是 `POST /api/integration/public/invoke`，异步结果是 `GET /api/integration/public/task/{taskId}`，无需管理端权限码，但接口自身仍按配置鉴权。

## 基础请求

```bash
curl -X POST http://localhost:8080/api/integration/public/invoke \
  -H 'Content-Type: application/json' \
  -d '{"jiekou_code":"sys_user_third_party_inbound","token":"TOKEN","users":[{"code":"U001","name":"Alice"}]}'
```

`jiekou_code` 被 `@JsonProperty` 解析为接口编码；`@JsonAnySetter` 会把其余字段原样放入 payload，运行时 JSON 不要再包 `payload`。客户端 IP 取 `X-Forwarded-For` 首个地址，其次 `X-Real-IP`，最后 `RemoteAddr`。

## 同步和异步

入站接口配置 `SYNC` 时直接查找 `processorBean` 并执行；配置 `ASYNC` 时返回 `accepted=true`、`taskId`、`traceId`，再查询：

```bash
curl 'http://localhost:8080/api/integration/public/task/TASK_ID'
```

任务不存在返回 `API_TASK_NOT_FOUND`。处理器未注册返回 `API_HANDLER_NOT_CONFIGURED`。

## 流程和排错

网关按 `apiCode + INBOUND` 获取快照 → 鉴权 → 参数组装 → 同步处理器或 Redis 任务 → 写日志。接口不存在、鉴权失败、映射失败和处理器异常都应从 `traceId` 查日志。当前公共入口不提供文件上传、多部分表单或原生 WebSocket；需要时应新增专用 Controller。
