# 出站调用

> 分类：后端 / 接口平台 / 出站  
> 版本：**V1.0.0**

## 源码位置和接入

内部调用入口是 `IntegrationFacade` / `IntegrationFacadeImpl`，执行器为 `ApiGatewayServiceImpl.invokeOutbound` 与 `ApiOutboundExecutorImpl`。业务服务只传稳定的 `apiCode` 和业务对象：

```java
@Resource
private IntegrationFacade integrationFacade;

public IntegrationExecuteResult pushUser(User user) {
    return integrationFacade.invoke("erp_user_sync", Map.of(
        "tenantId", TenantContext.get(),
        "users", List.of(Map.of("code", user.getAccount(), "name", user.getUsername()))
    ));
}
```

网关按 `OUTBOUND` 快照组装 body、query、headers、pathVariables，调用每个目标，再对响应做回写映射并写日志。多目标返回 `syncResults`/`asyncResults`；同步目标有失败时不会伪装成整体成功。

## 推荐用法

先配置同步目标验证字段和响应，再将慢目标切到异步。业务代码不要直接拼第三方 URL，不要绕过 `IntegrationFacade`，否则不会获得标准映射、重试和调用日志。

## 常见错误

接口不存在返回 `API_CONFIG_NOT_FOUND`；目标执行异常返回目标级 `success=false` 和 `errorMessage`；无目标时走兼容 legacy 目标，若未配置 URL 会失败。响应映射为空时返回原始响应，不应把“未映射”误认为“空响应”。

## 二开边界

新增协议或签名应扩展 `ApiOutboundExecutor`；不要在业务 Controller 里复制 HTTP、重试和日志逻辑。当前重试字段由目标配置承载，源码未提供熔断和限流策略，生产二开需增加隔离与指标。
