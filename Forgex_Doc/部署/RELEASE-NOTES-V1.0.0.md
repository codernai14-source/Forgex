# 🚀 Forgex V1.0.0 正式发布

> 从「跑得起来」到「扛得住生产」，Forgex 迈出了最关键的一步。

**V1.0.0 是 Forgex 的首个生产级里程碑。** 它标志着 Forgex 完成了从「企业级脚手架」到「生产级平台底座」的蜕变：内核经过真实生产环境持续打磨，架构在本版本正式定型，文档与代码全面同步至 V1.0.0。对于想要二次开发的团队，从这一版开始，模块边界清晰、依赖精确、扩展点稳定——你可以放心地在它之上构建自己的业务。

## ✨ 本版本核心更新

### 🏗️ 架构定型：Forgex_Common 模块化拆分
- 公共能力按职责拆分为 `Common_Contract / Core / Web / Data / Crypto / Excel / Infra` 七大模块，共享 DTO 下沉 `Domain_Contract`，内部 Feign 按提供方归属各 `*_Api` 模块
- 业务服务改为**精确 Maven 依赖**，告别「引一个包、拖全部类」的臃肿传递
- 旧 `Forgex_Common` 聚合保留为迁移期兼容层，存量二开项目平滑过渡

### 🔀 工作流引擎全面增强
- **审批人撤回**（recall）与发起人撤销（cancel）双通道，流转更从容
- **委托**：待办单条委托 + 委托设置，节点 `allowDelegate` 与权限双校验
- **超时扫描 Job** 自动发现超时任务并联动处理
- **抄送**全链路：抄送列表 + 我的抄送入口；待办支持加签/转交/委托，按「权限 ∩ 节点能力」精细管控
- 审批人支持**直属上级**（SUPERIOR）自动解析，组织汇报线直接打通审批链路

### 🔐 认证与安全
- **MFA 多因素认证**上线；登录与选租户拆分为**短期交互码**（interactionCode）安全链路
- 等保合规加固持续深化；国密 SM2/SM4、AES-256/RSA、Argon2，自带 KMS 密钥管理中心与字段透明加解密
- 敏感信息传输加密

### 🏭 生产级 MOM 能力闭环
- 工厂建模四级主数据：**车间 → 产线 → 工段 → 工序**，配套工作日历与班次体系
- 物料（原材料/半成品/成品）、供应商（协同/信用）、客户主数据全管理
- 标签模板全链路：类型/字段/模板/绑定/打印/补打；业务**编码规则中心**支撑单据自动取号

### 🎨 前端与多端体验
- **拖拽式个人工作台**：组件显隐/排序/尺寸记忆，布局分享，千人千面的数据驾驶舱
- `FxDynamicTable` 配置驱动表格：用户级列偏好、字典渲染、免手写导入导出
- Token 驱动深浅主题、`Ctrl+K` 全局搜索、多标签页签、消息语音播报、帮助中心与新手引导
- **穿透式国际化**五语言（简中/繁中/英/日/韩），界面与报错不再「两张皮」
- 原生 Android 端（Kotlin + Jetpack Compose）同步演进，适配 PDA 与工业平板

### 🛳️ 私有化交付
- Windows 离线交付包（内置 JRE、Nginx、Nacos 快照与控制中心）+ Linux 自动化套件，现场实施「即拷即用」

## ⬆️ 升级说明

- 从 0.8.x 升级：请先**备份数据库**，按 `database-upgrade` 目录顺序执行升级 SQL，并导入新版 Nacos 配置快照
- 详细变更与升级步骤见 [CHANGELOG](./CHANGELOG.md) 与 [部署文档](./README.md)
- 旧 `Forgex_Common` 聚合仅作迁移期兼容，建议二开项目按《Common 模块化拆分与二开指南》迁移到精确依赖
